# Reclamation

A Node.js application for processing customer and business reclamations with proper validation, priority calculation, and reference number generation.

## Installation

```bash
npm install
```

## Usage

Run the example:
```bash
npm start
```

Run tests:
```bash
npm test
```

## Features

- User and business reclamation processing
- Automatic priority calculation based on date
- Unique reference number generation
- Field validation
- Modular, reusable code structure
